Process

From creative direction to launch

I work comfortably from a creative director's design or brand guide. My part is to build it accurately, keep it consistent, and deliver on time.

Brief & design file

Read the brief, brand guide and Figma or XD file. List open questions before building, not halfway through.

Set up the system

Set global colours, fonts, buttons and reusable sections in Divi or Elementor, so every page stays consistent.

Build to the design

Match spacing, type and alignment to the file, and use custom HTML and CSS where the page builder falls short.

Responsive pass

Adjust every section for desktop, tablet and mobile, then check on real phones, not only in the browser preview.

Revisions

Turn around feedback rounds quickly and keep a short change log, so the team always knows what moved.

QA, launch & care

Run the pre-launch checklist and link audit, launch, then handle updates and improvements as the site grows.

Launch QA

Checks before every launch

This is my pre-launch checklist, including a full link audit. Clients should never be the ones who find a broken button.

Design accuracy

  • Spacing, fonts and colours match the design file
  • Headings and buttons consistent across pages
  • Images sharp, cropped well, never stretched
  • Favicon and social share image set

Responsive

  • Desktop, tablet (768–1024px) and mobile (360–414px)
  • Menus, sliders and popups work on touch
  • No horizontal scrolling or overlapping text
  • Tap targets big enough for thumbs

Links & forms

  • Crawl every page for broken internal and external links
  • Menu, button, phone and email links all tested
  • Forms send to the right inbox
  • 301 redirects in place for changed URLs

Launch

  • SSL active, with no mixed-content warnings
  • "Discourage search engines" turned off
  • Page titles, meta descriptions and alt text
  • Caching, compressed images and a backup before go-live
